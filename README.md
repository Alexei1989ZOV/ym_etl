# ym_etl
ETL project for Yandex Market seller

# Добавление нового отчета:
1) В файле app.configs.report_configs.py в словарь "TRANSFORM_CONFIGS" 
добавляем ключ с названием отчета и значение - вложенный словарь с ключом "columns" и значением - вложенным словарем по аналогии с существующими отчетами.
2) В папке app.storage.models создаем файл с моделью данных для нового отчета
3) В папке app.reports создаем файл с классом для нового отчета. Класс наследуется от BaseReport находящегося в той же папке в файле base.py.
В атрибутах класса указываем Эндпоинт согласно документации, тип отчета и указываем требуется ли business_id и/или campaign_id (смотрим документацию).
4) В папке app.raw_transformers создаем файл с трансформером для нового отчета. В файл копируем содержание аналогичного файла для уже работающих отчетов. Если в CSV, который отдает ЯМ, есть дата, то копируем например из отчета по аналитике продаж. Если даты нет, то при трансформации нужно ее добавить. Значит копируем содержание из отчета, в котором тоже дату сами добавляем принудительно. 
Нужно только изменить импорты (импортировать ранее созданную модель данных нового отчета), название класса и атрибуты (заменить ключи в конфиге), поправить типизацию.
5) В папке app.storage.repositories создаем файл с репозиторием для нового отчета по аналогии с имеющимися. Меняем импорт модели. В методах меняем типизацию и модель данных на нужную для этого отчета.
6) ЕТЛ пайплайн. В папке app.core.pipelines создаем файл с пайплайном для нового отчета.
В импортах меняем класс отчета, трансформер, репозиторий. Соответствующие изменения делаем в методах.
7) Оркестратор. В папке app.core.orchestrators создаем файл с оркестратором для нового отчета. 
Как обычно, путем копирования содержания аналогичного файла работающих отчетов.
В импортах меняем ЕТЛ пайплайн, репозиторий. Переименовываем класс. Вносим соответствующие правки в методах.
8) Собираем скрипт запуска в app.cli
9) В файл app.storage.init_db добавляем импорт модели данных нового отчета.
10) В Классе ReportPipeline который находится в файле app.core.pipeline в self.limiters добавляем лимиты нового отчета из документации.
11) Запускаем скрипт добавления новой таблицы в БД: python -m app.storage.init_db
